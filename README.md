# Matplotlib Practice

A Jupyter notebook for practicing Matplotlib's basic plotting and figure-layout features. It uses Apple and Microsoft stock-price values from 2014–2018 to demonstrate how to build and customize charts.

## What the notebook covers

- Plotting two data series on a line chart and labeling the axes
- Creating separate subplots to compare a line plot with a scatter plot
- Using `MaxNLocator` to show whole-number years on the x-axes
- Arranging plots in a 2×2 grid and selecting individual axes to plot on

## Run the notebook

Open `matplotlib_practice.ipynb` in Jupyter or VS Code and run its cells in order. The notebook uses Matplotlib and NumPy; make sure they are installed in the selected Python environment.
